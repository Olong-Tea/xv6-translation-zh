# 1.6 练习 (Exercises)

1. 编写一个程序，使用 UNIX 系统调用在一对管道（每个传输方向各一个管道）上，在两个进程之间像“打乒乓球”一样来回传递（ping-pong）一个字节。测量该程序的性能，单位为每秒交换的次数（exchanges per second）。

---

> **译者/解题提示：**
> 
> 这道练习题的核心考察点是 `pipe` 和 `fork` 的协同使用。由于管道是单向的（半双工），为了实现双向的“乒乓”通信，你必须创建**两个**管道：
> - 管道 A：父进程写，子进程读。
> - 管道 B：子进程写，父进程读。
>
> **基本伪代码逻辑结构如下：**
> 
> ```c
> int p2c[2]; // Parent to Child pipe
> int c2p[2]; // Child to Parent pipe
> pipe(p2c);
> pipe(c2p);
> 
> if (fork() == 0) {
>     // 子进程空间
>     close(p2c[1]); // 关闭父到子管道的写端
>     close(c2p[0]); // 关闭子到父管道的读端
>     
>     read(p2c[0], buf, 1);
>     write(c2p[1], buf, 1);
>     
>     exit(0);
> } else {
>     // 父进程空间
>     close(p2c[0]); // 关闭父到子管道的读端
>     close(c2p[1]); // 关闭子到父管道的写端
>     
>     write(p2c[1], "A", 1);
>     read(c2p[0], buf, 1);
>     
>     wait(0);
>     exit(0);
> }
> ```
> 
> *性能测量提示：* 要测量“每秒交换次数”，可以在父进程的写操作之前记录一次时间戳，使用一个 `for` 循环执行 N 次（例如 10000 次）完整的 ping-pong 交换，循环结束后再次记录时间戳。用 `N / (结束时间 - 开始时间)` 即可得出性能指标。在标准的 UNIX 环境下可以使用 `gettimeofday`，若在 xv6 环境下，则可参考内核提供的 `uptime` 系统调用。
