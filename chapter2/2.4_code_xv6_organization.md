# 2.4 代码剖析：xv6 架构 (Code: xv6 organization)

xv6 的内核源码位于 `kernel/` 子目录中。图 2.2（译者注：即上一节末尾的源文件概览表）列出了这些文件，并将它们按内核的主要职责进行了模块化划分：启动系统（引导，booting）、创建与控制进程、处理陷入（traps，包括中断和系统调用）、分配内存与配置虚拟地址、控制设备，以及管理文件系统。

  ```text
       +------------------+  MAXVA (最大虚拟地址)
       |    trampoline    |  (跳板页：用于在用户态和内核态之间切换)
       +------------------+
       |    trapframe     |  (陷入帧：保存进程被中断时的寄存器状态)
       +------------------+
       |       ...        |
       +------------------+
       |       heap       |  (堆：向上生长，用于动态内存分配)
       +------------------+
       |    user stack    |  (用户栈：向下生长)
       +------------------+
       |  user text       |  
       |  and data        |  (用户代码段和数据段)
    0  +------------------+
  ```
